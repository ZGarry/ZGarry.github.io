# 真人CS · 网页版 Counter-Strike

用 three.js 制作的 CS 风格第一人称射击游戏,**双击 `index.html` 即可在浏览器中游玩**,无需安装、无需联网。

## 玩法

5v5 人机对战,炸弹拆除模式(Dust 风格地图):T 在 A/B 包点安放 C4 并护包,CT 阻止或拆弹。标准赛制先到 13 胜,半场换边;含完整经济系统(击杀奖励、胜负奖金、连败补偿)。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 空格 / Ctrl / Shift | 移动 / 跳 / 蹲 / 静步 |
| 鼠标左键 | 开火 |
| 鼠标右键 | AWP 开镜(两档)/ 军刀重击 |
| R / G | 换弹 / 丢弃武器 |
| B | 购买菜单(冻结期与开局 10 秒内,在出生区) |
| 1 / 2 / 3 / 4 / 5 | 主武器 / 手枪 / 刀 / 手雷 / C4 |
| E(按住) | 安放 / 拆除炸弹 |
| Tab | 记分板 |
| Esc | 暂停菜单 |

## 武器

Glock-18 · USP-S · 沙漠之鹰 · MP5-SD · AK-47 · M4A4 · AWP · 军刀 · 高爆手雷 · 闪光弹 · 烟雾弹,均还原 CS 数值手感(弹道上扬、移动扩散、爆头倍率、护甲减伤、距离衰减)。

## 设置

主菜单可调:机器人难度(容易/普通/困难)、赛制(标准 13 胜 / 短局 5 胜)、鼠标灵敏度、音量。

全部画面为程序化生成,音效由 WebAudio 实时合成,无任何外部资源。
